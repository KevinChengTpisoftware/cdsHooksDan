CDS Hooks

Clinical Decision Support Hooks — 臨床決策支援服務展示與文件

Overview

CDS Hooks 是 HL7 定義的標準， 讓 EHR（電子病歷系統）在臨床工作流程的關鍵時刻，向外部 CDS 服務發起即時查詢， 並將建議卡片（Card）回饋給臨床人員。本站提供本專案所實作之 CDS 服務的說明與範例。

Architecture

EHR Hook 觸發端

在臨床流程觸發 hook（如 patient-view、order-select）， 將 context 與 FHIR authorization 送往 CDS Service。

CDS 決策服務

接收 hook request，查詢 FHIR Server 取得病患資料， 執行 CQL 規則引擎，回傳決策建議卡片。

FHIR 資料來源

提供標準化病患資料（MedicationRequest、Condition 等）， 供 CDS Service 進行臨床規則評估。

Discovery Endpoint

CDS Service 透過 /cds-services 端點公開可用的 hook 清單：

GET /cds-services

{
  "services": [
    {
      "hook": "patient-view",
      "id": "patient-greeting",
      "title": "Patient Greeting",
      "description": "顯示病患基本資訊與提示"
    },
    {
      "hook": "order-select",
      "id": "drug-interaction-check",
      "title": "Drug Interaction Check",
      "description": "檢查藥物交互作用並回傳警示卡片"
    }
  ]
}

Hook Request / Response

EHR 對指定 service 發送 POST 請求，CDS Service 回傳 Cards：

POST /cds-services/drug-interaction-check
Content-Type: application/json

{
  "hook": "order-select",
  "hookInstance": "d1577c69-...",
  "context": {
    "userId": "Practitioner/123",
    "patientId": "Patient/456",
    "selections": ["MedicationRequest/789"]
  },
  "fhirServer": "https://fhir.example.com",
  "fhirAuthorization": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "scope": "patient/*.read"
  }
}
// Response
{
  "cards": [
    {
      "uuid": "a1b2c3d4-...",
      "summary": "潛在藥物交互作用",
      "detail": "Warfarin 與 Aspirin 併用可能增加出血風險",
      "indicator": "warning",
      "source": { "label": "CDS Service" },
      "suggestions": [
        {
          "label": "更換為替代藥物",
          "actions": [...]
        }
      ]
    }
  ]
}

Card Indicator

Indicator意義使用時機
info資訊提示一般參考資訊，不需立即處理
warning警告需要臨床人員注意但非緊急
critical嚴重警示須立即處理的安全問題
